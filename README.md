# Roche_et_al_2026_ApJL_scaling-law_plotting-scripts
Atmospheric loss function (X_atm_calc.zip), supporting data (data_files/), plotting scripts (reproduce_figures.ipynb), a machine-readable version of Table 1 (impact_scenarios.csv), and an animated version of Figure 1 (movie.mp4) for Roche et al. (2026, ApJL) – Giant impacts preferentially remove low-mass atmosphere: a generalised scaling law for impact-driven atmospheric loss. Please download all files and directories in this repository if you wish to successfully reproduce any of the figures from this work.
